# Dentist+

## Requirements
- Node.js
- Docker + Docker Compose

## Installation
```bash
git clone https://github.com/albertglebocki-pl/dentistplus.git
cd dentistplus
npm install
````

## Usage

```bash
# Run development environment
npm run dev

# Run production environment
npm run prod

# Stop all running services
npm run stop

# Restart all services
npm run restart

# Stop all running services and remove volumes data
npm run clean
```
